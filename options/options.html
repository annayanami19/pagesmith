Pagesmith

Kelola edit yang tersimpan per domain, atur tampilan panel, dan cadangkan data kamu.

Domain tersimpan

0

Domain di daftar ini akan otomatis menerapkan editnya setiap kali dibuka. Menghapus domain di sini akan menghapus edit tersimpan dan mencabut izin aksesnya.

Tampilan

Warna kotak penanda elemen saat memilih dan mengedit.

Enter untuk menyimpan, Esc untuk membatalkan, Shift+Enter untuk baris baru.

Cadangan

Ekspor menyimpan seluruh edit dan pengaturan ke satu berkas JSON. Impor bisa menggabungkan dengan data yang ada atau menggantinya seluruhnya.

Hapus data

Menghapus data tidak bisa dibatalkan. Ekspor dulu bila kamu masih membutuhkannya.
